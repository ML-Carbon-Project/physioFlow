# Changelog

All notable changes to PhysioFlow are recorded here.

The reference point is **v1.0, commit `bc69e10`** — the version cited in the
metadata table (C1/C2) of the Software Impacts submission. Anything listed under
*Unreleased* came after that commit and is therefore **not** part of the version
the article describes.

Format loosely follows [Keep a Changelog](https://keepachangelog.com/1.1.0/).

## Unreleased

### Fixed

- **Dunnett now uses the residual mean square of the fitted design.** The
  procedure estimated the variance from the treatment replicates alone, through
  `scipy.stats.dunnett` over the raw data, while every other mean-comparison
  method received `ms_error`/`df_error` from the model. In a randomised complete
  block design, a factorial or a Latin square this pushed the block and
  second-factor variation into the error term and inflated the p-values. **This
  changes results**: on `sk_rcbd`, treatment E moves from p = 0.0385 (differs
  from the control at 5%) to p = 0.0539 (does not). `dunnett_test` now takes
  `ms_error`, `df_error` and `means_override` (for ANCOVA adjusted means), and
  the experimental-design page passes the model's values. Omitting both
  arguments keeps the one-way estimate, which is the correct one for a
  completely randomised design. Validated against `multcomp::glht` on
  `aov(y ~ tra + blk)`; see section 3d of
  [`docs/validacao_externa.md`](docs/validacao_externa.md).
  Section 5 of the article documents this limitation as it stands in v1.0.
- **The downloadable script generated for Dunnett called the wrong function.**
  `_METHOD_FUNCS` had no `dunnett` key, so the generator fell back to
  `scott_knott_groups` while labelling the block "Dunnett". It now emits a real
  `dunnett_test` call carrying the model's error term.
- **Continuous integration passes.** The workflow had never completed: `ruff`
  was installed unpinned, so each run inherited the newest rules; `mypy` aborted
  on the numpy stubs, which use PEP 695 `type` statements that require
  `python_version >= 3.12`; and `pytest` could not import `src`, because CI calls
  `pytest` directly rather than `python -m pytest`. `ruff` and `mypy` are now
  pinned, numpy stubs are not followed, and `pythonpath` is declared.

### Changed

- The multivariate-t integrator behind Dunnett runs with a fixed seed. Its CDF
  is estimated by quasi-Monte Carlo, so the same data previously produced
  slightly different p-values on each run.
- The caption under the Dunnett table states how many degrees of freedom the
  comparison used (PT/EN/ES).

### Added

- `data/data-README.md` and `data/data-LICENSE.txt`: provenance and licence of
  every file under `data/`, stating the terms of each origin rather than
  asserting a single licence over datasets the authors do not own.
- Post-hoc comparisons checked against R: Tukey against `stats::TukeyHSD`, LSD,
  Duncan and Scheffé against `agricolae`, Dunnett against `multcomp`. References
  are frozen in `data/sample/test/posthoc_reference_R.json`, regenerated by
  `scripts/gerar_referencia_posthoc_R.R`, so the suite does not require R.
- `reproduce_examples.py`: headless reproduction of the public examples in the
  article (Yates oats split-plot ANOVA; Palmer penguins correlation and
  classification).

## v1.0 — 2026-09-27 (`bc69e10`)

First public release, and the version described in the Software Impacts
manuscript: nine pages covering upload with schema validation, the replicate
pipeline, exploratory analysis with statistical guard-rails, supervised
regression and classification, geospatial analysis, STL decomposition and the
experimental-design module, in a trilingual (PT/EN/ES) interface.
