# Datasets shipped with PhysioFlow

Every file under `data/` in this repository is either public or synthetic. The
ecophysiology field campaign behind the figures of the article belongs to an
ongoing research project and cannot be released: it is excluded from version
control, and nothing derived from its measured values is included here.

This document and `data-LICENSE.txt` beside it also ship with the Code Ocean
reproducible capsule (DOI 10.24433/CO.9901925.v1), where the same files sit
flat under `/data` and `/data/test`. The names are kept identical in both places
so the two copies stay comparable.

## Synthetic ecophysiology dataset

`sample/physiology_synthetic.csv` (1661 rows, 31 columns) is generated by
`scripts/make_synthetic_physiology.py`, with a fixed seed. It reproduces the
reference schema and the *structural* properties the article discusses, not the
measurements:

- farm, crop and land use are perfectly redundant (Cramer's V = 1.00), so the
  confounding guard-rail has something to detect;
- the sampling grid is deliberately incomplete, so the cleaning pipeline
  discards the same share of rows the real campaign does;
- chlorophyll has two replicates and leaf area index three, so every replicate
  mode of the pipeline is exercised;
- only three distinct collection dates, so the STL guard-rail fires.

Values are drawn from plausible physiological distributions. They are not
measurements and must not be used as such.

## Public datasets (`sample/test/`)

Used to check the experimental-design engine against published results and
against R.

| File | Source | Used for |
|---|---|---|
| `yates.oats.txt` | Yates (1935) oats trial, as distributed with R `nlme::Oats` | split-plot ANOVA, Table 2 of the article |
| `penguins.csv` | Palmer Penguins, Gorman et al., Palmer Station LTER (CC0) | one-way ANOVA, Tukey, factorial, ANCOVA, correlation, classification |
| `sweetpotato.csv` | `sweetpotato` dataset of the R package `agricolae` (GPL) | LSD, Duncan, Scheffe and Dunnett against `agricolae` and `multcomp` |
| `plantgrowth.csv` | `PlantGrowth` of the R `datasets` package, from Dobson (1983) | same post-hoc comparisons, with a control level for Dunnett |
| `BESAG_ELBATAN.txt` | BESAG El Batan wheat trial, ASReml Cookbook | randomised complete blocks with a numeric block |
| `australia.soybean.txt` | Australian multi-environment soybean trial, ASReml Cookbook | protein-oil correlation |
| `sk_crd1.csv`, `sk_rcbd.csv`, `sk_sorghum.csv` | datasets shipped with the R package `ScottKnott` (GPL); `sk_sorghum` is the sorghum yield example of Jelihovschi, Faria and Allaman (2014) | Scott-Knott mean grouping against the official implementation |
| `exemplo_faixas.csv`, `exemplo_nested.csv` | balanced synthetic trials generated for the strip-plot and nested designs | three-error-stratum and hierarchical ANOVA |
| `SPRING_BARLEY.txt` | ASReml Cookbook | shipped for completeness, not used by the tests |
| `OATS.csv` | same oats trial in comma-separated form | shipped for completeness |

## Provenance of the reference values

`sample/test/posthoc_reference_R.json` holds the pairwise decisions, critical
values and Dunnett p-values computed in R for the datasets above, together with
the versions that produced them (R 4.6.0, `agricolae` 1.3.7, `multcomp` 1.4.32).
It is regenerated by `scripts/gerar_referencia_posthoc_R.R`, which reads the same
CSV files, and it is frozen as regression tests in
`tests/test_sample_datasets.py::TestPostHocVsR`, so the suite guards those values
without requiring R. The comparison itself is tabulated in
`docs/validacao_externa.md`.

The Code Ocean capsule carries its own reference set under `code/reference/`,
recomputed by R inside the reproducible run rather than read from this JSON.
